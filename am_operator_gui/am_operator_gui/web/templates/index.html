Hardware Guide: Launch All topic contractRequired external publishers and local outputs

Keep Simulation unchecked. Launch All starts the AM adapters, path processing, controller stack and followers only. It does not start the base driver, UR driver, Vicon bridge, TF/robot-description stack, controller manager, or safety system.

Before Launch All, run ros2 topic info -v <topic> and ros2 topic echo <topic> --once for every selected external input; check the controller with ros2 control list_controllers --controller-manager <manager>. A command topic normally gains its publisher only after its follower starts, but the hardware driver/controller subscriber must already exist.
