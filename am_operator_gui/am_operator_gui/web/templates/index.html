Nozzle transforms

Both transforms describe the same nozzle from different starting frames. They are equal only if the measured Vicon EE frame coincides with the robot flange. XYZ is in metres in the starting frame; rotation describes the nozzle axes relative to that frame. RPY uses roll/pitch/yaw about X/Y/Z, in degrees.

Vicon EE / marker → nozzleMeasured pose · hardware feedback

Defines the nozzle relative to the frame measured by Vicon. Applied before converting the nozzle pose into the control frame. Use identity only when Vicon already reports the nozzle-tip pose. Initial values retain the previous Vicon calibration; adjust them for your measured EE frame. Restart Pose Adapters after changing this topic or transform.

Robot flange → nozzleKinematic chain · selected platform

Defines the nozzle relative to the robot flange (robot_arm_tool0) for arm control. This does not calibrate the Vicon measurement.

Hardware feedback: measured Vicon EE → Vicon-to-nozzle offset → control frame → nozzle pose → spray-distance offset → deposition pose.
